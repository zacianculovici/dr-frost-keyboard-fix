# dr-frost-keyboard-fix

> [!NOTE]
> This repository is not approved by or related to Dr Frost Maths, it is separate without permission from Dr Frost Maths itself. 

## Description
This is a fix for Dr Frost Maths algebra questions (on the website) that makes the input system work on mobile devices with hardware keyboards. I encountered it when using Dr Frost on an ipad with a hardware keyboard, and could not stand having to type with the tiny on-screen keyboard. 

### What it does:
This is designed to run as a bookmaklet (or other injected javascript), so that it is easy to run and access. It simply listens for input in the input field, and then runs ```preventDefault()``` and inserts the character manually via MathQuill or the corresponding virtual keyboard button.
